03 / PRIVACY

Optional connections and reports.

Nebula can contact GitHub to check for releases; the update check can be turned off. DLSS is downloaded from NVIDIA when you request it. Optional Discord status communicates with your local Discord client.

Crash reports and session recordings are saved locally. They are shared only if you attach them to a report. Review them before uploading.

This website has no analytics scripts or account system. External links take you to services such as GitHub and Discord, which have their own privacy policies.
