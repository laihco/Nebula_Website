02 / QUICK ANSWERS

Before you start.

Is Nebula free?

Yes. Nebula is free software under the GNU GPL v3. You need your own copy of Super Mario Galaxy; game files are not included.

Is v2 available yet?

Not yet. v2 is coming soon. The current public release is v1.0.1. The v2 features described here are for the upcoming update.

Is this an emulator?

No. In v2, Super Mario Galaxy runs as native code built from SMGCommunity’s Petari decompilation. The original levels, music, story and gameplay come from your own game.

Which copy of the game do I need?

The supported copy is the North American Wii release, RMGE01, revision 0. For v2, prepare an ISO, RVZ or extracted folder. Support for other regions has not been announced.

Can I play on Linux, Steam Deck, Android or Mac?

Windows is available now, and an Android beta is released. Linux and SteamOS are in development; macOS is planned.

Can I use a Dolphin save?

Yes. Close the game, then use Advanced → Import saves in the launcher. See the save guide for the steps.

Will all Wii mods work?

No. File replacements and compatible texture packs work, but mods that patch the Wii’s machine code may not run in a native game. Check the mod guide before importing.

Is Nebula made by Nintendo?

No. Nebula is an independent project by the Nebula developers. It is not affiliated with, endorsed by or sponsored by Nintendo.
