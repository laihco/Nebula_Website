Mods & texture packs

What works in v2, how to import it and what to check if something breaks.

v2 guide · Coming soon. These instructions cover the upcoming update. The current public download is v1.0.1. Check downloads

01 / COMPATIBILITY

Check the mod before importing.

v2 supports Riivolution mods, disc file replacements, Dolphin-format texture packs, HD movie replacements and changes to Nebula’s menu text. Use mods made for the supported region of Super Mario Galaxy.

Some Wii mods patch the Wii’s machine code. Those changes cannot run directly in a native game. Nebula reports unsupported code changes; a mod that needs them may not work. Texture pack support is not part of v1.0.1.

02 / IMPORT

Add a mod or texture pack.

  1. 01

    Open Mods

    Use the launcher’s Mods tab or the in-game Mods page.

  2. 02

    Choose the file

    Import a zip, 7z, rar or folder, or drop it onto the game window. Extract password-protected archives first.

  3. 03

    Enable and arrange

    Move the mod into the enabled list. When two enabled mods change the same file or texture, the higher one takes priority.

  4. 04

    Apply and restart

    Choose any Riivolution options the mod provides, then Apply. Restart when prompted.

03 / PACKS & MOVIES

Textures and HD movies.

Dolphin-format texture packs use tex1_ PNG or DDS files. In Graphics → Texture packs, On loads replacements as needed; Preload loads them at startup and uses more memory.

HD movies can replace the game’s videos with MP4, WebM or MKV files supplied by a compatible pack. 4K video needs hardware decoding. If a video stutters, use a lower-resolution version or turn off that replacement.

04 / IF SOMETHING BREAKS

Try without mods first.

Disable mods and try the same part of the game again. If the problem stops, enable them one at a time. Check the region, mod version and priority order. Error codes NEB-M01 and NEB-M02 can identify the mod or file involved.
