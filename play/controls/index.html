02 / POINTER & MOTION

Aim, spin and tilt.

  • The mouse aims the pointer. On Xbox, use the right stick.
  • Supported PlayStation, Switch and Steam controllers can aim with the gyro. Turn gyro off to use the right stick for the pointer.
  • Use the recenter button to bring the pointer back to the middle.
  • Shake a motion-capable controller to spin, or use a mapped spin button.
  • Tilt controls steer the Star Ball and ray surfing sections. Keyboard and Xbox controls use movement inputs instead.
  • Adjust pointer speed, sensitivity, dead zones and vibration in Controls.

04 / CUSTOMISE

Change any binding.

Open Controls in the launcher or the game. Choose the connected device and select an action. Add up to four inputs for each Wii input, or clear an existing binding. Profiles are stored per controller family.

Open settings with F1, View + Menu, Share + Options or Minus + Plus. Use Apply to keep changes. General → Button icons lets you choose a fixed button style instead of following the current controller.
