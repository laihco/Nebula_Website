Saves & Miis

Back up your progress, continue from Dolphin and choose a Mii for your file.

v2 guide · Coming soon. These instructions cover the upcoming update. The current public download is v1.0.1. Check downloads

BACK UPIMPORTSAVE FILESMII ICONS
01 / BACK UP

Keep a copy of your progress.

Close the game. In the launcher, open Advanced → Export saves. Nebula creates a dated ZIP file containing your save data. Keep it somewhere outside the installation folder.

02 / IMPORT

Continue from Dolphin.

  1. 01

    Find your save

    In Dolphin, right-click Super Mario Galaxy and choose Open Wii Save Folder. Use a save for the supported North American version.

  2. 02

    Close the game

    Do not import or export while the game is running.

  3. 03

    Import in Nebula

    Open the launcher → Advanced → Import saves → From a folder, then choose the Dolphin save folder.

  4. 04

    Choose your file

    Start the game and check the imported save. Nebula backs up your existing saves before importing.

03 / SAVE FILES

Find or restore a save.

On Windows, saves are stored in %LOCALAPPDATA%\Nebula\saves. Before importing, Nebula moves existing saves to a dated saves-backup-… folder. You can also import a previously exported Nebula save ZIP through the launcher.

Setup’s Uninstall mode keeps saves and settings. Export a backup before a major update or moving to another computer.

04 / MII ICONS

Bring your Miis.

In v2, open Settings → General → Import Miis. Imported Miis appear in the save-file icon picker. Wii, DS, 3DS, Wii U, Switch, Mii Studio and Mii Creator sources are supported; exact file-format guidance will accompany the release.
