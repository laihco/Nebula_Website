01 / A NEW ORBIT

A familiar galaxy.
A different kind of launch.

Nebula brings Super Mario Galaxy to Windows through static recompilation: translating the original game’s code into a native PC experience using your own copy of the game.

It’s a community project and a work in progress. For current availability, known issues, and development updates, the project’s GitHub is the place to start.

02 / READY FOR LAUNCH

Ready when you are.

Start with the official project documentation. It covers the supported game version, hardware requirements, and installation.

  1. 01

    Bring your own copy

    You’ll need the USA release of Super Mario Galaxy (RMGE01, revision 0). Game files are not provided here.

  2. 02

    Check your flight computer

    A 64-bit Windows 10 or 11 PC and a Direct3D 12 compatible GPU. Read the project guide for the full requirements.

  3. 03

    Follow the setup guide

    Get the installer and follow the instructions maintained by the Nebula project.

03 / FROM THE OBSERVATORY
Is this an official Nintendo release?

No. Nebula is an independent community project. This website is an unofficial design demo and is not affiliated with Nintendo or the Nebula developers.

Can I play on Mac, Linux, or my phone?

This page describes the documented Windows version. Visit the project’s repository for the latest platform support. The website itself works on mobile and desktop.

Where can I find help or report a bug?

Read the known issues or visit the project’s issue tracker.
