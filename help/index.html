Setup rejects my game

Check the region and revision. v2 currently requires the North American RMGE01 revision 0 release. Modified or patched game images may fail the check.

The game is slow

Lower internal resolution, ray tracing quality or the interpolation target. Try DLSS / FSR 3 and turn off ambient occlusion. See performance settings.

My controller is not detected

Reconnect the controller, check Controls → Input and select Auto. Some devices need a specific connection or driver. Check your controller.

DLSS or ray tracing is missing

DLSS needs an NVIDIA RTX GPU and a first-use download followed by a restart. Ray tracing needs DXR 1.1 and Shader Model 6.6 on Windows. Check the in-game System page.

The game crashes with mods

Disable mods and try again. Re-enable them one at a time, checking region and priority. Read the mod guide.

The game will not start

Update your graphics driver. On a PC with two GPUs, choose the other GPU in the launcher. If an error code appears, look it up below before changing files.

A replacement movie stutters

4K replacement movies need hardware video decoding. Try a lower-resolution replacement or disable that movie pack.

Audio skips during play

Close programs using a lot of CPU time and try again. Include your hardware and background programs if the issue continues.

My save is missing

Close the game and check your dated save-backup folders. Import through the launcher rather than overwriting files. Save backup and import guide.

Windows or antivirus warns about a download

Use only the official release files. Read the release notes for signing and antivirus information. If a warning appears, ask in Discord before running the file.

03 / REPORT A BUG

Help us reproduce it.

Search existing issues first. If the problem is new, include the steps that make it happen and what you expected to see.

  • Nebula version and whether it is v1 or v2.
  • Windows version, CPU, GPU and graphics driver.
  • Galaxy and mission, plus the exact steps to reproduce the problem.
  • Graphics settings you changed and all enabled mods.
  • A screenshot or video for visual problems.

For a v2 crash, attach the newest .txt report and, if requested, the .dmp file from %LOCALAPPDATA%\Nebula\crashes. Review files before sharing. Reports stay on your computer until you attach them.

For a v2 visual or timing issue, open the launcher → Advanced → Recording (next launch) → Lightweight. Play until the problem happens, quit, then attach the ZIP from the folder Nebula opens. Use Detailed recording if asked. In v1, use Advanced → Open diagnostics for available crash logs.
