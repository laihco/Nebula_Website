01 / LOOKUP

Find your code.

No matching codes. Try another word or use the bug report guide.

NEB-C01

The game's code crashed, with no mod changing the game.

Try this: Start again; if it repeats at the same place, report it with the report file.

NEB-C02

The game stopped itself with an error (its own fatal check); the report quotes its message.

Try this: Start again. If the same problem repeats, report it with the report file.

NEB-C03

The game's code ran out of stack space.

Try this: Start again. If the same problem repeats, report it with the report file.

NEB-M01

The game crashed while mods changed its files or code; the report lists them.

Try this: Turn the mods off and play again; if it no longer happens, turn them on one at a time.

NEB-M02

The game crashed within 15 seconds of reading a file a mod supplies; the report names the mod and the file.

Try this: Turn that mod off, or check it is made for this game's region and version.

NEB-T01

A texture pack image stopped Nebula while it loaded; the report names the file.

Try this: Remove the image from the pack or save it again as a PNG.

NEB-V01

A replacement movie stopped Nebula while it played; the report names the file.

Try this: Remove the video or convert it to an H.264 MP4.

NEB-G01

The graphics driver reset the graphics card (device removed, hung or lost).

Try this: Update the driver; turn off ray tracing and frame generation or lower the internal resolution.

NEB-G02

The renderer stopped on another error; the report quotes it.

Try this: Update the driver; report it if it repeats.

NEB-R01

Nebula ran out of memory.

Try this: Close other programs, set texture packs to On instead of Preload, or lower the internal resolution.

NEB-N01

Nebula's own code crashed (not the game's).

Try this: Start again; report it if it repeats.

NEB-N02

Nebula stopped on an unexpected error; the report quotes it.

Try this: Start again. If it repeats, report it with the report file.

NEB-N03

Nebula stopped itself (abort).

Try this: Start again. If it repeats, report it with the report file.

NEB-N04

Nebula stopped on an internal error while starting.

Try this: Start again. If it repeats, report it with the report file.

NEB-S01

The game content (`game.pak`) was not found or could not be opened.

Try this: Run Nebula Setup again, or choose the content in Nebula settings > Advanced.

NEB-S02

The game content is damaged.

Try this: Run Nebula Setup again to rebuild it from your disc image.

NEB-S03

Nebula's files do not match each other.

Try this: Install or update Nebula again.

NEB-S04

The graphics card could not start the game.

Try this: Update the driver; with two graphics cards, choose the other in Nebula settings > Display.

NEB-S05

Nebula's settings file could not be read.

Try this: Rename `config.ini` in Nebula's settings folder to start with default settings.

NEB-S06

Nebula was started with options it does not know.

Try this: Start Nebula from its launcher or shortcut.

Include the report.

Attach the newest report from your Nebula crashes folder and describe the steps that caused the problem. Review the report before sharing it.
