01 / BEFORE YOU START

Your game. Your computer.

You need your own copy of Super Mario Galaxy. Nebula does not include or download game files. Setup prepares your game locally on your computer.

Requirement Current Windows baseline
Operating system Windows 10 version 1803 or newer, or Windows 11 (64-bit)
Processor x86-64 CPU with AVX2
Graphics Direct3D 12-compatible GPU
Memory 8 GB RAM
Storage About 5 GB for Nebula and the game
Your game Super Mario Galaxy, North America, RMGE01, revision 0
Accepted formats ISO, RVZ or an extracted game folder

The supported disc includes English, French and Spanish. Other regions have not been announced for v2. A tested minimum CPU/GPU list and recommended hardware tiers will be published with the release.

02 / INSTALL

Set up Nebula on Windows.

  1. 01

    Get Nebula Setup

    Use the download page to find the current release. v2 is not available yet.

  2. 02

    Choose your game

    Run Nebula Setup and select your supported ISO, RVZ or extracted game folder. Setup checks the game and revision before importing.

  3. 03

    Install

    Choose Install. Setup prepares the game on your PC and adds Start menu shortcuts. Keep the installer for updates and repairs.

  4. 04

    Start playing

    Open Nebula from the Start menu. Adjust the launcher’s Display, Graphics, Controls or Audio options, then choose Save and play.

Download only from the project’s releases. If Windows or your antivirus flags a file, check the release notes and ask for help in Discord before continuing.

03 / FIRST LAUNCH

Make it yours.

After choosing a save file, press F1 to open settings. On Xbox, use View + Menu; on PlayStation, Share + Options; on Switch, Minus + Plus. You can also open settings from the pause menu.

  • Start at a low internal resolution on older PCs, then increase it until you are happy with performance.
  • Set the aspect ratio to Auto to match your window. Use Display for HUD resolution to keep menus and text sharp.
  • Try native interpolation for a high-refresh display. It adds smoother motion while the game keeps its normal speed.
  • Ray tracing costs more GPU time. Start with Low or Medium, then adjust resolution or use DLSS / FSR 3 if needed.
  • Use Apply to keep changes, or Undo to discard them. Display changes have a confirmation countdown.

04 / UPDATES & SAVES

Keep your progress.

Nebula can check for updates at launch. You can also run Setup again to update, repair, restore the previous version or uninstall. Uninstalling keeps your saves and settings.

Before a major update, close the game and export a save backup from the launcher’s Advanced tab. Final v1-to-v2 upgrade instructions will be included with the v2 release.
